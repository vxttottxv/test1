# 구인구직 사이트 백엔드 (FastAPI) - 개발 지시서

이 문서는 `구인구직_API_명세서.md`를 기반으로, 개발 AI(Claude Code 등)에게 그대로 넘겨서
로컬 환경에서 실행 가능한 FastAPI 백엔드를 만들도록 지시하기 위한 문서입니다.

---

## 1. 기술 스택

| 구분 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | FastAPI | |
| ORM | SQLAlchemy 2.0 | |
| 마이그레이션 | Alembic | |
| DB (로컬) | SQLite | 별도 DB 설치 없이 바로 실행 가능. 나중에 PostgreSQL로 교체 쉬움 |
| 인증 | JWT (python-jose) + passlib(bcrypt) | Access/Refresh Token |
| 검증 | Pydantic v2 | FastAPI 기본 내장 |
| 서버 | Uvicorn | 로컬 실행용 |
| 패키지 관리 | venv + requirements.txt (또는 poetry) | 단순하게 venv 권장 |
| 테스트 | pytest + httpx | |

## 2. 프로젝트 폴더 구조

```
job-board-api/
├── app/
│   ├── main.py                # FastAPI 앱 진입점
│   ├── config.py              # 환경변수/설정 (.env 로드)
│   ├── database.py            # SQLAlchemy engine, session
│   │
│   ├── models/                # SQLAlchemy 모델 (DB 테이블)
│   │   ├── user.py
│   │   ├── company.py
│   │   ├── job_posting.py
│   │   └── application.py
│   │
│   ├── schemas/                # Pydantic 스키마 (요청/응답 DTO)
│   │   ├── auth.py
│   │   ├── job_posting.py
│   │   └── application.py
│   │
│   ├── routers/                 # API 엔드포인트 (도메인별 분리)
│   │   ├── auth.py             # /auth/*
│   │   ├── job_postings.py     # /job-postings/*
│   │   └── applications.py     # /users/me/applications
│   │
│   ├── services/                # 비즈니스 로직 (라우터에서 분리)
│   │   ├── auth_service.py
│   │   ├── job_posting_service.py
│   │   └── application_service.py
│   │
│   ├── core/
│   │   ├── security.py         # 비밀번호 해싱, JWT 생성/검증
│   │   ├── dependencies.py     # get_current_user 등 FastAPI Depends
│   │   └── exceptions.py       # 커스텀 예외 + 공통 에러 응답 포맷
│   │
│   └── seed/
│       └── seed_data.py        # Company/JobPosting 샘플 데이터 삽입 스크립트
│
├── alembic/                     # 마이그레이션 파일
├── tests/
│   ├── test_auth.py
│   ├── test_job_postings.py
│   └── test_applications.py
│
├── .env.example
├── .gitignore
├── requirements.txt
├── alembic.ini
└── README.md
```

**설계 원칙 (개발 AI에게 강제할 것)**
- 라우터(routers)는 요청을 받아 서비스(services)를 호출만 하고, 비즈니스 로직/DB 쿼리는 서비스 레이어에 둘 것
- 모든 응답은 명세서의 공통 응답 포맷(`{"success": true, "data": ...}` / `{"success": false, "error": {...}}`)을 따를 것 → 전역 예외 핸들러로 통일 처리
- DB 세션은 FastAPI `Depends`로 주입, 요청마다 커넥션 열고 닫기
- 비밀번호는 반드시 bcrypt 해싱 후 저장 (평문 저장 금지)

## 4. DB 스키마 (SQLAlchemy 모델 기준)

```
User
- id (PK)
- email (unique, not null)
- password_hash (not null)
- user_type (enum: SEEKER, COMPANY)
- name
- phone
- created_at

Company
- id (PK)
- company_name
- location
- logo_url

JobPosting
- id (PK)
- company_id (FK -> Company)
- title
- job_category
- employment_type
- career_level
- career_years_min
- career_years_max
- location
- salary_type
- salary_min
- salary_max
- required_skills (JSON 또는 콤마구분 문자열)
- description (text)
- qualifications (text)
- preferred_qualifications (text)
- benefits (text)
- apply_start_at
- apply_end_at
- status (enum: OPEN, CLOSED)
- created_at

Application
- id (PK)
- job_posting_id (FK -> JobPosting)
- user_id (FK -> User)
- applicant_name
- applicant_phone
- applicant_email
- cover_letter (text, nullable)
- status (enum: SUBMITTED / 이번 범위는 단일 상태만)
- applied_at
- UNIQUE constraint (job_posting_id, user_id)  # 중복 지원 방지
```

## 5. 로컬 실행 방법 (개발 AI가 README에 정리해야 할 내용)

```bash
# 1. 가상환경 생성 및 활성화
python -m venv venv
source venv/bin/activate      # Windows는 venv\Scripts\activate

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 환경변수 파일 생성
cp .env.example .env

# 4. DB 마이그레이션
alembic upgrade head

# 5. (선택) 샘플 데이터 삽입
python -m app.seed.seed_data

# 6. 서버 실행
uvicorn app.main:app --reload --port 8000

# 7. API 문서 확인 (FastAPI 자동 생성)
# http://localhost:8000/docs
```

## 6. 개발 AI에게 전달할 지시문 (그대로 복사해서 사용)

아래 내용을 개발 AI(Claude Code 등)에게 그대로 붙여넣으면 됩니다.

```
첨부한 "구인구직_API_명세서.md"를 기반으로 Python FastAPI 백엔드를 만들어줘.
로컬 환경(SQLite)에서 바로 실행 가능해야 해.

[기술 스택]
- FastAPI + SQLAlchemy 2.0 + Alembic + SQLite(로컬용) + JWT 인증(python-jose, passlib)

[구현 범위 - 명세서의 아래 5개 기능만]
1. 회원가입 (POST /auth/signup)
2. 로그인 (POST /auth/login), 토큰 재발급(POST /auth/refresh), 로그아웃(POST /auth/logout)
3. 채용공고 목록 조회 (GET /job-postings) - 키워드/직무/지역/고용형태/경력 필터 + 페이지네이션
4. 채용공고 상세 조회 (GET /job-postings/{id})
5. 지원하기 (POST /job-postings/{id}/applications) + 내 지원 내역 조회 (GET /users/me/applications)

[폴더 구조]
아래 구조를 그대로 따라줘.
(위 "2. 프로젝트 폴더 구조" 섹션 통째로 붙여넣기)

[필수 규칙]
- 라우터는 얇게 유지하고, 실제 로직은 services 레이어에 작성
- 모든 API 응답은 {"success": true, "data": ...} / {"success": false, "error": {"code":..., "message":...}} 포맷 통일 (전역 예외 핸들러 사용)
- 비밀번호는 bcrypt로 해싱해서 저장
- 지원하기 API는 로그인(JWT) 필요 + userType이 SEEKER인지 검증
- 같은 공고에 같은 유저가 중복 지원 못하도록 DB unique constraint + 에러 처리
- 마감(apply_end_at 지난) 공고에는 지원 불가하도록 검증
- Alembic으로 마이그레이션 관리 (모델 수정 시 마이그레이션 파일도 같이 생성)
- 샘플 채용공고 데이터 10~20개 넣는 시드 스크립트 작성 (프론트/테스트에서 바로 써볼 수 있게)
- README.md에 로컬 실행 방법(venv 생성부터 서버 실행까지) 정리
- pytest로 각 엔드포인트 기본 테스트 코드 작성 (회원가입/로그인/공고조회/지원 성공 및 실패 케이스)

[진행 방식]
1. 먼저 폴더 구조와 requirements.txt, .env.example부터 생성
2. 모델(SQLAlchemy) + 마이그레이션 작성 후 알려줘
3. 그 다음 auth -> job-postings -> applications 순서로 라우터/서비스 구현
4. 마지막에 시드 스크립트, README, 테스트 코드 작성
5. 각 단계마다 무엇을 했는지 간단히 요약해줘
```
